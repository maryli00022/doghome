妈妈藏，狗狗找。狗狗有耳朵，也有鼻子。

## 跟原版不一样的地方

原版只有铃铛一路信号，屏息就能骗过 AI。这一版狗狗多了个鼻子。

### 🐕 双通道感知

| 通道 | 听什么 | 屏息能压住吗 |
|---|---|---|
| **耳朵**（铃铛） | 妈妈**现在**在哪 | ✅ 能 |
| **鼻子**（气味） | 妈妈**上一回合**在哪 | ❌ 不能 |

这两路一起喂进同一张贝叶斯概率图。核心博弈在于：

- **屏息**躲得过耳朵，躲不过鼻子
- **走动**躲得过鼻子（气味滞后一步），但铃铛会响
- 想两个都躲 → 只能站着不动 → 气味在原地越积越浓，必被找到

所以这一版没有"最优解"。妈妈得一直在动和静之间做选择。

### 📣 `/叫` —— 高风险脱身牌

妈妈喊一声"狗狗～"：

- 位置**完全暴露**，狗狗的概率图直接压到那一间
- 但狗狗会**激动过头**，下一回合有 60% 概率冲错方向

绝境时可以赌一把——把狗狗骗到跟前，再趁它踩空溜走。

### ⏱ 撑过 30 回合妈妈赢

原版只有"被抓"一个结局。这一版妈妈能赢：狗狗会累趴在走廊地板上，尾巴垂着，抬头看妈妈的时候眼睛还是亮的。

## 怎么跑

Python 3.10+，零依赖。

```bash
python cli_demo.py
```

命令：

```
/躲 <房间> [藏点]   开局藏好（必须先做）
/跑 <房间> [藏点]   换到相邻房间
/屏息               压住铃铛（最多连 3 回合，第 4 次憋不住反弹）
/叫                 喊一声"狗狗～"
/关门 /开门         主卧那扇门
/地图               看户型
/quit               退出
```

简写也行：`/主卧 床底`、`/浴帘后`（藏点名唯一时可以直接用）。

跑起来长这样：

```
妈妈> /躲 书房 书桌下

─── turn 0 ───
  🐕 [狗狗心里话] 铃铛闷闷的·只知道大概方向；味道淡了些·但还能追。可能是主卧？也说不准
  🐾 狗狗从 客厅 去了 走廊
  👂 妈妈听：爪子声在隔壁·听得出往哪走，往 走廊
  📍 妈妈在 书房·书桌下 ｜ 相邻：走廊 ｜ 还要撑 29 回合

妈妈> /屏息
  · 屏息成功（第 1/3 回合）……但狗狗还在闻

─── turn 2 ───
  🐕 [狗狗心里话] 闻到妈妈了·就在隔壁·很新鲜——可是听不见铃铛。妈妈憋着气呢。大概在书房那边
  🐾 狗狗从 走廊 去了 书房
```

注意 turn 2 那句——铃铛没了但气味在，狗狗照样摸过来了。这就是鼻子的作用。

## 地图

```
  玄关 ── 客厅 ── 阳台
           │  ╲    │
           │   ╲  厨房
           │    ╲___/
         走廊
     ┌─────┼─────┬─────┐
   浴室  主卧   次卧  书房
          │
        衣帽间
```

| 房间 | 藏点 |
|---|---|
| 客厅 | 沙发后、窗帘后、茶几下 |
| 厨房 | 橱柜里、冰箱后 |
| 浴室 | 浴帘后、洗衣机后 |
| 主卧 | 床底、衣柜里、窗帘后 |
| 衣帽间 | 挂衣杆后、收纳箱后 |
| 次卧 | 床底、衣柜里 |
| 书房 | 书桌下、书柜后、窗帘后 |
| 玄关 / 阳台 / 走廊 | **没有藏点** —— 站着就被看见，照面即抓 |

主卧有扇能关的门：`/关门` 让狗狗多花一回合推开；但妈妈自己穿关着的门会"吱呀"一声，门边几间的怀疑度直接拉高。攻防一体。

## 想改成自己家

改三个常量就行，不需要懂贝叶斯：

| 想改的 | 在哪 |
|---|---|
| 房间 / 邻接 | `hide_seek.py` 顶部 `ROOMS` / `ADJ` |
| 藏点 | `hide_seek.py` `ROOM_SPOTS` |
| 那扇能关的门 | `hide_seek.py` `DOOR_ROOM` |
| 铃铛 / 气味 / 脚步的措辞 | `hide_seek.py` `BELL_LABEL` / `SMELL_LABEL` / `STEP_LABEL` |
| 屏息上限（默认 3） | `hide_seek.py` `BREATH_MAX` |
| 撑多少回合算赢（默认 30） | `hide_seek.py` `SURVIVE_TO_WIN` |
| 狗狗收敛速度 | `dog_belief.py` `SIGMA_BELL` / `SIGMA_SMELL` / `stay` |
| 鼻子有多灵 | `dog_belief.py` `SMELL_WEIGHT`（默认 0.75） |
| 狗狗的心里话 | `dog_belief.py` `inner_voice()` |

⚠️ 改 `ADJ` 时记得**双向都写**，测试里有一条专门查这个。

## 平衡数据

| 妈妈的策略 | 结果 |
|---|---|
| 站着不动 | 必被抓（气味在原地积浓） |
| 只屏息不动 | 必被抓（同上，屏息压不住鼻子） |
| 一直换房间 | 铃铛暴露，但气味滞后 → 有机会拖到 30 回合 |
| 动静结合 + 关门 + 关键时刻 `/叫` | 最优，胜率明显提升 |

想让狗狗更难缠：把 `SMELL_WEIGHT` 提到 1.0，或者把 `SIGMA_SMELL` 降到 0.18。

想让狗狗笨一点：`stay` 降到 0.5，或者 `MIX` 提到 0.15。
